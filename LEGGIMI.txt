SOCOCUP V2 - FASE 3A: SOCOSOCIAL REALE

1. In Supabase V2 -> SQL Editor -> New query, incolla ed esegui 01_SUPABASE.sql.
2. Nel repository GitHub SocoCup-V2 sostituisci SOLO index.html con quello di questo ZIP.
3. Carica js/socosocial.js nella cartella js.
4. NON toccare js/login.js, js/profilo.js, js/app.js, PIN, Turnstile, SocoCup V1.
5. Apri il sito, Ctrl+F5, clicca SocoSocial e prova un post.

FUNZIONI: feed, post, commenti, like, eliminazione dei propri contenuti, salvataggio Supabase, RLS.
LIMITI: questa fase NON importa automaticamente notizie e NON genera ancora risposte automatiche. Per notizie reali occorre un feed attendibile e una funzione server; per account automatizzati occorre un profilo trasparente che li identifichi come tali. Non pubblicare finte notizie o far passare account automatizzati per persone reali.
