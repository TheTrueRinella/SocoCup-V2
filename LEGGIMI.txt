SOCOCUP V2 — LOGIN PRESIDENTI CON TURNSTILE

File da caricare nel repository GitHub SocoCup-V2:
1. index.html -> radice del repository (sostituisce index.html)
2. js/login.js -> cartella js/ (nuovo file)

Il file js/login-preview.js può rimanere nel repository ma NON viene più caricato.
NON sostituire gli altri file del sito (js/app.js, CSS, dati ecc.).

REQUISITI:
- Edge Function sococup-team-login pubblicata e Verify JWT with legacy secret OFF.
- Supabase Auth Anonymous Sign-Ins e CAPTCHA Turnstile abilitati.
- Il widget Turnstile deve autorizzare thetruerinella.github.io.
- Per ripristinare l'accesso dopo il refresh, la policy RLS SELECT di sococup_profiles
  deve consentire all'utente authenticated di leggere SOLO il proprio user_id.
- La funzione SQL deve essere stata installata e le variabili d'ambiente
  SUPABASE_URL e SUPABASE_SERVICE_ROLE_KEY disponibili nella Edge Function.

NOTE:
- Questa integrazione NON concede ancora privilegi di scrittura alle sezioni del sito.
- Il blocco PIN a livello squadra non sostituisce un rate limit per IP/utente.
- Il login va verificato dal vivo: non è stato testato contro il progetto Supabase.
- Il tasto Esci chiude la sessione locale, non cancella il profilo sul database.
